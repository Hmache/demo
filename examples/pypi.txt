## Finding a package

# 900,000 projects
PyPI hosts over 900,000 Python projects. Let's open one.
> highlight "Type '/' to search projects"
> go to https://pypi.org/project/kokoro-onnx/
> wait for "Project description"

## The project page

# Install command
The install command is right at the top, ready to copy.
> highlight "pip install kokoro-onnx"

# Release history
The release history shows how actively a project is maintained.
> click "Release history"
> wait for "Release notifications"
> zoom into "Release history" x1.6
> wait 1s
> zoom out

# Release files
And every release ships its files, with hashes, right here.
> click "Release files"
> wait 1s
